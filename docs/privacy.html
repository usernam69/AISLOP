Privacy Policy

Last updated: October 13, 2026

AISLOP is a personal tool used only by the owner of the SubtleSpawns YouTube channel. It is not offered to the public.

What it accesses

With the owner's permission (Google sign-in), AISLOP uses the YouTube Data API to upload videos, update their privacy setting, add them to playlists, read video statistics, post comments on the channel's own videos and read public comments on those videos.

How data is used and stored

This data is used only to run the channel. Video statistics and a log of uploaded videos are stored in the owner's own files. Comment text is used to draft replies that the owner reviews by hand. Nothing is sold or shared with anyone, and no data is used for advertising.

Google API Services

AISLOP's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
