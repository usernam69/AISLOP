AISLOP Privacy Policy

Last updated: October 13, 2026

This policy explains what data AISLOP accesses, how it is used, stored and shared, and how to remove access. AISLOP is an automation tool used only by the owner of the SubtleSpawns YouTube channel to make and upload daily tech-news Shorts.

Google user data AISLOP accesses

When the channel owner signs in with Google, AISLOP requests these YouTube permissions:

  • Upload videos (youtube.upload): to upload the channel's Shorts.
  • Manage your YouTube account (youtube.force-ssl): to set a video's visibility, add videos to the channel's playlists, read video statistics (views, likes, comment counts), post a comment on the channel's own videos, and read the public comments viewers leave on those videos (comment text and the commenter's public display name).

AISLOP does not access Gmail, Drive, contacts, payment information or any other Google data.

How the data is used

  • Video statistics are used to show the channel owner which topics and upload times perform best.
  • Viewer comments are used to draft replies. Drafts are never posted automatically; the owner reviews and posts them by hand.
  • Data is not used for advertising, is not sold, and is not used to train AI models.

Storage and retention

The Google sign-in token is stored in the owner's own files and in encrypted GitHub Actions secrets, and is used only to call the YouTube Data API. A log of uploaded videos and their statistics is kept in the owner's files for as long as the channel uses AISLOP. Draft replies are overwritten on each daily run. Rendered videos are deleted after 14 days.

Sharing

Google user data is not shared with anyone. To write video scripts and reply drafts, AISLOP sends news headlines and, for reply drafts, viewer comment text to an AI text service (OpenRouter or Google Gemini). No sign-in tokens or account details are sent.

Google API Services and YouTube

AISLOP's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. AISLOP uses YouTube API Services; by using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Removing access and deleting data

Access can be removed at any time at myaccount.google.com/permissions or Google security settings. After removal, AISLOP can no longer access the account, and the owner can delete the stored token and logs.

Contact

Questions about this policy: contact the channel through youtube.com/@SubtleSpawns.
